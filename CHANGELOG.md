# Changelog

All notable changes to the **Obsidian Glow** VS Code theme will be documented in this file.

## [0.1.0] - 2026-05-20
### Added
- Initial release of the **Obsidian Glow** theme suite.
- **Original Obsidian Glow**: Glare-free deep carbon slate background (`#1a1b26`) paired with electric lavender ambient accents (`#bb9af7`).
- **Carbon OLED**: Ultra-deep pitch black cockpit backing (`#0d0e15`) for maximum contrast and high-brilliance neon glowing accents.
- **Ambient Light**: Daytime metallic silver dashboard (`#f2f4f8`) paired with rich charcoal instruments and active orchid accents (`#8f58e8`).
- **Sunset Sand**: Luxurious warm beige/ivory leather dashboard (`#fcf8f2`) with deep espresso text and warm gold-orchid LED highlights (`#a55eea`).
- Warmer, more legible Blue-Gray comment colors (`#5f6b93`).
- High-fidelity icon/badge resized from `obsidian-glow.png`.
