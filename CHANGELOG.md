# Changelog

All notable changes to the **Obsidian Glow** VS Code theme suite will be documented in this file.

## [0.2.0] - 2026-05-20
### Added
- New updated high-fidelity logo design (`icon.png`).
- Three new dashboard cockpit variations:
  - **Carbon OLED**: Deep pitch-black backing (`#0d0e15`) for high contrast.
  - **Ambient Light**: Silver-brushed daytime digital panel (`#f2f4f8`).
  - **Sunset Sand**: Premium cream ivory leather finish dashboard (`#fcf8f2`).
- Integrated Python and JavaScript syntax preview screenshots.
- Streamlined and simplified documentation.

## [0.1.0] - 2026-05-20
### Added
- Initial release of the **Obsidian Glow** color theme.
- Soothing carbon slate background (`#1a1b26`) inspired by automotive screens.
- Warmer, highly legible Blue-Gray comment highlights (`#5f6b93`).
- Signature Glow Lavender ambient LED strip accent (`#bb9af7`).
